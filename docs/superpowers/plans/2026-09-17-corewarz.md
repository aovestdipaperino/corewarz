# CoreWarz Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an extended Core War implementation in Rust: an ICWS'94-faithful MARS plus an extended dialect adding bitwise arithmetic, a value-producing compare, conditional branches, and core-resident subroutines, with an assembler, a CLI, and a TUI visualizer.

**Architecture:** A Cargo workspace of four crates with an acyclic dependency graph pointing at `corewarz-core`. The VM is I/O-free and mode-free in its hot loop; the dialect is enforced only by the assembler and by warrior admission. All observation flows through one `Observer` trait so the TUI and the test harness never reach into VM internals.

**Tech Stack:** Rust 2021 (rustc 1.98), `ratatui` + `crossterm` for the TUI, `clap` for the CLI, `proptest` for property tests, `pmars` (built from source) as the classic-mode correctness oracle.

**Spec:** `docs/superpowers/specs/2026-09-17-corewarz-design.md`

## Global Constraints

- Workspace crates: `corewarz-core`, `corewarz-asm`, `corewarz-tui`, `corewarz-cli`, all under `crates/`.
- Dependency direction is strictly: `asm -> core`, `tui -> core`, `cli -> {core, asm, tui}`. Nothing depends on `cli`. `core` depends on nothing in the workspace.
- `corewarz-core` performs no I/O and has no terminal, file, or text dependencies.
- Every `Cargo.toml` uses: `authors = ["Enzo Lombardi <enzinol@gmail.com>"]`, `edition = "2021"`, `license = "MIT"`, `repository = "https://github.com/aovestdipaperino/corewarz"`.
- All core values are `u32` held permanently folded into `0..core_size`. All modular arithmetic goes through `Core::fold`; no bare `%` on addresses anywhere else.
- Word width for shift operations is 32 bits. A shift count >= 32 produces 0.
- A value `v` is "negative" iff `v > core_size / 2`. It is "positive" iff `v != 0 && v <= core_size / 2`.
- The VM has no runtime errors. No function in `corewarz-core`'s execution path returns `Result`.
- Follow the Rust API Guidelines: doc comments on every public item, `#[must_use]` where appropriate, strong types over primitives, no `unwrap()` outside tests.
- Run `cargo clippy --all-targets -- -D warnings` and `cargo fmt --check` before every commit.
- Default config: core size 8000, 80000 cycles, 8000 max processes, 100 max warrior length, 100 minimum separation.

```rust
//! Instruction representation.
//!
//! An [`Instruction`] is a small `Copy` struct so that the core can be a flat,
//! cache-friendly `Vec`. Field values are always folded into `0..core_size`.

/// A Redcode operation.
///
/// Variants up to and including [`Opcode::Nop`] are ICWS'94 classic opcodes.
/// The remainder are CoreWarz extensions, available only in the extended
/// dialect.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
pub enum Opcode {
    // --- classic ---
    Dat,
    Mov,
    Add,
    Sub,
    Mul,
    Div,
    Mod,
    Jmp,
    Jmz,
    Jmn,
    Djn,
    Spl,
    Seq,
    Sne,
    Slt,
    Nop,
    // --- extended ---
    And,
    Or,
    Xor,
    Shl,
    Shr,
    Not,
    Tst,
    Jez,
    Jnz,
    Jlz,
    Jgz,
    Call,
    Ret,
    Push,
    Pop,
}

impl Opcode {
    /// Returns `true` if this opcode is a CoreWarz extension and therefore
    /// illegal in the classic dialect.
    #[must_use]
    pub const fn is_extended(self) -> bool {
        !matches!(
            self,
            Opcode::Dat
                | Opcode::Mov
                | Opcode::Add
                | Opcode::Sub
                | Opcode::Mul
                | Opcode::Div
                | Opcode::Mod
                | Opcode::Jmp
                | Opcode::Jmz
                | Opcode::Jmn
                | Opcode::Djn
                | Opcode::Spl
                | Opcode::Seq
                | Opcode::Sne
                | Opcode::Slt
                | Opcode::Nop
        )
    }
}

/// An instruction modifier, selecting which fields an operation acts on.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
pub enum Modifier {
    /// A-field of source to A-field of destination.
    A,
    /// B-field of source to B-field of destination.
    B,
    /// A-field of source to B-field of destination.
    AB,
    /// B-field of source to A-field of destination.
    BA,
    /// Both fields, straight through.
    F,
    /// Both fields, crossed.
    X,
    /// The whole instruction.
    I,
}

/// An addressing mode.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
pub enum AddrMode {
    /// `#` — the field value is the operand itself.
    Immediate,
    /// `$` — the field value is an offset from the current instruction.
    Direct,
    /// `*` — indirect through the A-field of the pointed-at instruction.
    IndirectA,
    /// `@` — indirect through the B-field of the pointed-at instruction.
    IndirectB,
    /// `{` — decrement the pointed-at A-field, then indirect through it.
    PredecA,
    /// `<` — decrement the pointed-at B-field, then indirect through it.
    PredecB,
    /// `}` — indirect through the pointed-at A-field, then increment it.
    PostincA,
    /// `>` — indirect through the pointed-at B-field, then increment it.
    PostincB,
}

/// A single core cell.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Instruction {
    pub opcode: Opcode,
    pub modifier: Modifier,
    pub a_mode: AddrMode,
    pub a: u32,
    pub b_mode: AddrMode,
    pub b: u32,
}

impl Instruction {
    /// The instruction every core cell holds before warriors are loaded:
    /// `DAT.F $0, $0`.
    pub const DAT_ZERO: Instruction = Instruction {
        opcode: Opcode::Dat,
        modifier: Modifier::F,
        a_mode: AddrMode::Direct,
        a: 0,
        b_mode: AddrMode::Direct,
        b: 0,
    };
}

impl Default for Instruction {
    fn default() -> Self {
        Self::DAT_ZERO
    }
}
```

```rust
//! Core memory.

use crate::config::Config;
use crate::instruction::Instruction;
use crate::warrior::WarriorId;

/// The circular memory array that warriors fight inside.
///
/// Every address arithmetic operation in CoreWarz goes through [`Core::fold`].
/// This is the only place in the codebase where modular wrapping happens.
#[derive(Debug, Clone)]
pub struct Core {
    cells: Vec<Instruction>,
    owners: Vec<Option<WarriorId>>,
    size: u32,
}

impl Core {
    /// Creates a core of `config.core_size` cells, every cell `DAT.F $0, $0`
    /// and unowned.
    #[must_use]
    pub fn new(config: &Config) -> Self {
        let n = config.core_size as usize;
        Self {
            cells: vec![Instruction::DAT_ZERO; n],
            owners: vec![None; n],
            size: config.core_size,
        }
    }

    /// The number of cells in the core.
    #[must_use]
    pub const fn size(&self) -> u32 {
        self.size
    }

    /// Reduces any integer to a valid core address, wrapping in both
    /// directions.
    #[must_use]
    pub fn fold(&self, value: i64) -> u32 {
        let m = i64::from(self.size);
        (((value % m) + m) % m) as u32
    }

    /// Reads the instruction at `addr`.
    ///
    /// # Panics
    /// Panics if `addr` is not a folded address. Callers must fold first.
    #[must_use]
    pub fn get(&self, addr: u32) -> Instruction {
        self.cells[addr as usize]
    }

    /// Writes `instr` at `addr` and records `warrior` as the cell's owner.
    ///
    /// # Panics
    /// Panics if `addr` is not a folded address. Callers must fold first.
    pub fn set(&mut self, addr: u32, instr: Instruction, warrior: WarriorId) {
        self.cells[addr as usize] = instr;
        self.owners[addr as usize] = Some(warrior);
    }

    /// The warrior that last wrote `addr`, if any.
    ///
    /// The ownership map has no effect on the rules; it exists so that a
    /// visualizer can colour the battlefield.
    #[must_use]
    pub fn owner(&self, addr: u32) -> Option<WarriorId> {
        self.owners[addr as usize]
    }
}
```

**Interfaces:**
- Consumes: `Core`, `Instruction`, `AddrMode`, `WarriorId` (Tasks 1–2).
- Produces: `Operands { a_ptr: u32, b_ptr: u32, ira: Instruction, irb: Instruction }` and `resolve(core: &mut Core, pc: u32, instr: Instruction, owner: WarriorId) -> Operands`.

This is the ICWS'94 evaluation phase. It runs before every opcode dispatch, for every opcode, classic and extended alike. `a_ptr` and `b_ptr` are folded absolute addresses; `ira` and `irb` are *copies* of the instructions at those addresses taken at resolution time, which is what makes self-modifying writes behave correctly.

Pre-decrements and post-increments mutate the core as a side effect, and the increment of a post-increment operand happens after *both* operands are resolved, in A-then-B order.

```rust
//! ICWS'94 operand evaluation.
//!
//! Resolution runs before every opcode dispatch and is shared by every
//! instruction, classic and extended. It is also the only place where the
//! pre-decrement and post-increment addressing modes mutate the core.

use crate::core::Core;
use crate::instruction::{AddrMode, Instruction};
use crate::warrior::WarriorId;

/// The result of evaluating an instruction's two operands.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Operands {
    /// Folded absolute address the A-operand designates.
    pub a_ptr: u32,
    /// Folded absolute address the B-operand designates.
    pub b_ptr: u32,
    /// Snapshot of the instruction at `a_ptr`, taken during resolution.
    pub ira: Instruction,
    /// Snapshot of the instruction at `b_ptr`, taken during resolution.
    pub irb: Instruction,
}

/// A post-increment deferred until both operands have been resolved.
#[derive(Clone, Copy)]
struct Deferred {
    addr: u32,
    a_field: bool,
}

fn eval_one(
    core: &mut Core,
    pc: u32,
    mode: AddrMode,
    field: u32,
    owner: WarriorId,
    deferred: &mut Option<Deferred>,
) -> u32 {
    match mode {
        AddrMode::Immediate => pc,
        AddrMode::Direct => core.fold(i64::from(pc) + i64::from(field)),
        AddrMode::IndirectA | AddrMode::IndirectB => {
            let ptr = core.fold(i64::from(pc) + i64::from(field));
            let cell = core.get(ptr);
            let off = if mode == AddrMode::IndirectA { cell.a } else { cell.b };
            core.fold(i64::from(ptr) + i64::from(off))
        }
        AddrMode::PredecA | AddrMode::PredecB => {
            let ptr = core.fold(i64::from(pc) + i64::from(field));
            let mut cell = core.get(ptr);
            if mode == AddrMode::PredecA {
                cell.a = core.fold(i64::from(cell.a) - 1);
            } else {
                cell.b = core.fold(i64::from(cell.b) - 1);
            }
            core.set(ptr, cell, owner);
            let off = if mode == AddrMode::PredecA { cell.a } else { cell.b };
            core.fold(i64::from(ptr) + i64::from(off))
        }
        AddrMode::PostincA | AddrMode::PostincB => {
            let ptr = core.fold(i64::from(pc) + i64::from(field));
            let cell = core.get(ptr);
            let off = if mode == AddrMode::PostincA { cell.a } else { cell.b };
            *deferred = Some(Deferred { addr: ptr, a_field: mode == AddrMode::PostincA });
            core.fold(i64::from(ptr) + i64::from(off))
        }
        }
}

fn apply(core: &mut Core, d: Option<Deferred>, owner: WarriorId) {
    if let Some(d) = d {
        let mut cell = core.get(d.addr);
        if d.a_field {
            cell.a = core.fold(i64::from(cell.a) + 1);
        } else {
            cell.b = core.fold(i64::from(cell.b) + 1);
        }
        core.set(d.addr, cell, owner);
    }
}

/// Evaluates both operands of `instr` executing at `pc`.
///
/// Applies pre-decrement side effects immediately and post-increment side
/// effects after both operands have been evaluated, in A-then-B order, as
/// ICWS'94 requires.
pub fn resolve(core: &mut Core, pc: u32, instr: Instruction, owner: WarriorId) -> Operands {
    let mut da = None;
    let mut db = None;
    let a_ptr = eval_one(core, pc, instr.a_mode, instr.a, owner, &mut da);
    let ira = core.get(a_ptr);
    let b_ptr = eval_one(core, pc, instr.b_mode, instr.b, owner, &mut db);
    let irb = core.get(b_ptr);
    apply(core, da, owner);
    apply(core, db, owner);
    Operands { a_ptr, b_ptr, ira, irb }
}
```

```rust
//! Modifier-driven field selection.
//!
//! [`field_pairs`] is the single source of truth for what every binary
//! operation does under each modifier. Arithmetic, bitwise, and comparison
//! opcodes all plug into it, which is why they share one set of semantics.

use crate::instruction::{Instruction, Modifier};

/// One of an instruction's two value fields.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Field {
    A,
    B,
}

impl Field {
    /// Reads this field from `instr`.
    #[must_use]
    pub const fn get(self, instr: &Instruction) -> u32 {
        match self {
            Field::A => instr.a,
            Field::B => instr.b,
        }
    }

    /// Writes `value` into this field of `instr`.
    pub fn set(self, instr: &mut Instruction, value: u32) {
        match self {
            Field::A => instr.a = value,
            Field::B => instr.b = value,
        }
    }
}

/// The (source, destination) field pairs a binary operation acts on under
/// `modifier`.
///
/// `.I` is treated as `.F` here; opcodes for which `.I` means "the whole
/// instruction" (only `MOV`, `SEQ`, and `SNE`) handle it before consulting
/// this table.
#[must_use]
pub const fn field_pairs(modifier: Modifier) -> &'static [(Field, Field)] {
    match modifier {
        Modifier::A => &[(Field::A, Field::A)],
        Modifier::B => &[(Field::B, Field::B)],
        Modifier::AB => &[(Field::A, Field::B)],
        Modifier::BA => &[(Field::B, Field::A)],
        Modifier::F | Modifier::I => &[(Field::A, Field::A), (Field::B, Field::B)],
        Modifier::X => &[(Field::A, Field::B), (Field::B, Field::A)],
    }
}
```

```rust
//! `MOV` and the classic arithmetic opcodes.

use crate::core::Core;
use crate::exec::fields::field_pairs;
use crate::exec::operand::Operands;
use crate::instruction::{Instruction, Modifier};
use crate::warrior::WarriorId;

/// What executing one instruction tells the scheduler to do next.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum StepResult {
    /// Continue at the next instruction.
    Continue,
    /// Continue at this folded absolute address.
    Jump(u32),
    /// Skip the next instruction.
    Skip,
    /// The process dies.
    Die,
    /// Continue at the next instruction and also spawn a process at this
    /// folded absolute address.
    Split(u32),
}

/// A classic arithmetic operation.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum BinOp {
    Add,
    Sub,
    Mul,
    Div,
    Mod,
}

/// Executes `MOV`.
pub fn exec_mov(
    core: &mut Core,
    instr: Instruction,
    ops: Operands,
    owner: WarriorId,
) -> StepResult {
    if instr.modifier == Modifier::I {
        core.set(ops.b_ptr, ops.ira, owner);
        return StepResult::Continue;
    }
    let mut dst = core.get(ops.b_ptr);
    for (src_f, dst_f) in field_pairs(instr.modifier) {
        dst_f.set(&mut dst, src_f.get(&ops.ira));
    }
    core.set(ops.b_ptr, dst, owner);
    StepResult::Continue
}

/// Executes `ADD`, `SUB`, `MUL`, `DIV`, or `MOD`.
///
/// Division or modulo by zero kills the process. Fields written before the
/// zero divisor is encountered keep their new values, as ICWS'94 requires.
pub fn exec_binop(
    core: &mut Core,
    instr: Instruction,
    ops: Operands,
    owner: WarriorId,
    op: BinOp,
) -> StepResult {
    let mut dst = core.get(ops.b_ptr);
    let mut died = false;
    for (src_f, dst_f) in field_pairs(instr.modifier) {
        let s = i64::from(src_f.get(&ops.ira));
        let d = i64::from(dst_f.get(&ops.irb));
        let value = match op {
            BinOp::Add => core.fold(d + s),
            BinOp::Sub => core.fold(d - s),
            BinOp::Mul => core.fold(d * s),
            BinOp::Div | BinOp::Mod if s == 0 => {
                died = true;
                break;
            }
            BinOp::Div => core.fold(d / s),
            BinOp::Mod => core.fold(d % s),
        };
        dst_f.set(&mut dst, value);
    }
    core.set(ops.b_ptr, dst, owner);
    if died {
        StepResult::Die
    } else {
        StepResult::Continue
    }
}
```

Semantics, so they are not guessed at:

- `JMP` jumps to `a_ptr` unconditionally.
- `JMZ target, test` examines the B-operand's fields: `.A` tests the A-field, `.B` the B-field, `.F`/`.X`/`.I` require **both** fields to be zero.
- `JMN` is the exact negation of `JMZ`: under `.F`/`.X`/`.I` it jumps if **either** field is non-zero.
- `DJN` decrements the selected field(s) of the B-operand *in core*, then jumps if any decremented field is non-zero.
- `SPL` continues at the next instruction and spawns a process at `a_ptr`. The continuing process is enqueued first.
- `SEQ`/`SNE` compare under `.I` by comparing whole instructions; otherwise field pairs. `SLT` compares `a < b` per field pair and requires all pairs to hold.
- `DAT` always kills. `NOP` always continues.

```rust
//! Classic control-flow, comparison, and process opcodes.

use crate::core::Core;
use crate::exec::classic_data::StepResult;
use crate::exec::fields::field_pairs;
use crate::exec::operand::Operands;
use crate::instruction::{Instruction, Modifier};
use crate::warrior::WarriorId;

/// A skip-style comparison opcode.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum SkipCmp {
    /// Skip if equal (`SEQ`, also spelled `CMP`).
    Seq,
    /// Skip if not equal (`SNE`).
    Sne,
    /// Skip if the A-operand is less than the B-operand (`SLT`).
    Slt,
}

/// Executes `DAT`. Always kills the process.
#[must_use]
pub const fn exec_dat() -> StepResult {
    StepResult::Die
}

/// Executes `NOP`. Always continues.
#[must_use]
pub const fn exec_nop() -> StepResult {
    StepResult::Continue
}

/// Executes `JMP`.
#[must_use]
pub const fn exec_jmp(ops: Operands) -> StepResult {
    StepResult::Jump(ops.a_ptr)
}

/// The B-operand field values this modifier examines for a conditional jump.
fn tested_fields(modifier: Modifier, irb: &Instruction) -> Vec<u32> {
    match modifier {
        Modifier::A | Modifier::BA => vec![irb.a],
        Modifier::B | Modifier::AB => vec![irb.b],
        Modifier::F | Modifier::X | Modifier::I => vec![irb.a, irb.b],
    }
}

/// Executes `JMZ`: jumps when every examined field is zero.
#[must_use]
pub fn exec_jmz(instr: Instruction, ops: Operands) -> StepResult {
    if tested_fields(instr.modifier, &ops.irb).iter().all(|v| *v == 0) {
        StepResult::Jump(ops.a_ptr)
    } else {
        StepResult::Continue
    }
}

/// Executes `JMN`: jumps when any examined field is non-zero.
#[must_use]
pub fn exec_jmn(instr: Instruction, ops: Operands) -> StepResult {
    if tested_fields(instr.modifier, &ops.irb).iter().any(|v| *v != 0) {
        StepResult::Jump(ops.a_ptr)
    } else {
        StepResult::Continue
    }
}

/// Executes `DJN`: decrements the examined fields in core, then jumps when any
/// of them is non-zero.
pub fn exec_djn(
    core: &mut Core,
    instr: Instruction,
    ops: Operands,
    owner: WarriorId,
) -> StepResult {
    let mut dst = core.get(ops.b_ptr);
    let touch_a = matches!(
        instr.modifier,
        Modifier::A | Modifier::BA | Modifier::F | Modifier::X | Modifier::I
    );
    let touch_b = matches!(
        instr.modifier,
        Modifier::B | Modifier::AB | Modifier::F | Modifier::X | Modifier::I
    );
    let mut non_zero = false;
    if touch_a {
        dst.a = core.fold(i64::from(dst.a) - 1);
        non_zero |= dst.a != 0;
    }
    if touch_b {
        dst.b = core.fold(i64::from(dst.b) - 1);
        non_zero |= dst.b != 0;
    }
    core.set(ops.b_ptr, dst, owner);
    if non_zero {
        StepResult::Jump(ops.a_ptr)
    } else {
        StepResult::Continue
    }
}

/// Executes `SPL`.
#[must_use]
pub const fn exec_spl(ops: Operands) -> StepResult {
    StepResult::Split(ops.a_ptr)
}

/// Executes `SEQ`, `SNE`, or `SLT`.
#[must_use]
pub fn exec_skip_cmp(instr: Instruction, ops: Operands, cmp: SkipCmp) -> StepResult {
    let condition = match (cmp, instr.modifier) {
        (SkipCmp::Seq, Modifier::I) => ops.ira == ops.irb,
        (SkipCmp::Sne, Modifier::I) => ops.ira != ops.irb,
        (SkipCmp::Seq, m) => field_pairs(m)
            .iter()
            .all(|(s, d)| s.get(&ops.ira) == d.get(&ops.irb)),
        (SkipCmp::Sne, m) => field_pairs(m)
            .iter()
            .any(|(s, d)| s.get(&ops.ira) != d.get(&ops.irb)),
        (SkipCmp::Slt, m) => field_pairs(m)
            .iter()
            .all(|(s, d)| s.get(&ops.ira) < d.get(&ops.irb)),
    };
    if condition {
        StepResult::Skip
    } else {
        StepResult::Continue
    }
}
```

```rust
//! Battle observation.
//!
//! This trait is the only interface through which anything outside the VM
//! learns what a battle is doing. The TUI implements it to drive its display;
//! the differential test harness implements it to produce an execution trace.

use crate::warrior::WarriorId;

/// Receives notifications as a battle runs.
///
/// Every method has a default no-op implementation, so an implementor need
/// only override what it cares about.
pub trait Observer {
    /// A cell was read during operand resolution or execution.
    fn on_read(&mut self, addr: u32) {
        let _ = addr;
    }

    /// A cell was written by `warrior`.
    fn on_write(&mut self, addr: u32, warrior: WarriorId) {
        let _ = (addr, warrior);
    }

    /// `warrior` is about to execute the instruction at `addr`.
    fn on_exec(&mut self, addr: u32, warrior: WarriorId) {
        let _ = (addr, warrior);
    }

    /// A process of `warrior` died executing the instruction at `addr`.
    fn on_death(&mut self, warrior: WarriorId, addr: u32) {
        let _ = (warrior, addr);
    }
}

/// An [`Observer`] that does nothing.
///
/// The compiler erases it entirely, so headless runs pay no observation cost.
#[derive(Debug, Clone, Copy, Default)]
pub struct NullObserver;

impl Observer for NullObserver {}
```

```rust
//! Per-warrior process queues.

use std::collections::VecDeque;

/// A warrior's FIFO queue of process program counters.
///
/// The queue has a fixed capacity; pushing to a full queue is silently
/// ignored, which is how `SPL` becomes a no-op at the process limit.
#[derive(Debug, Clone)]
pub struct ProcessQueue {
    entries: VecDeque<u32>,
    capacity: usize,
}

impl ProcessQueue {
    /// Creates an empty queue holding at most `capacity` processes.
    #[must_use]
    pub fn new(capacity: u32) -> Self {
        Self { entries: VecDeque::with_capacity(capacity as usize), capacity: capacity as usize }
    }

    /// Enqueues `pc` at the back, unless the queue is full.
    ///
    /// Returns `true` if the process was enqueued.
    pub fn push(&mut self, pc: u32) -> bool {
        if self.entries.len() >= self.capacity {
            return false;
        }
        self.entries.push_back(pc);
        true
    }

    /// Dequeues the next process to run.
    pub fn pop(&mut self) -> Option<u32> {
        self.entries.pop_front()
    }

    /// The process at the front of the queue, without dequeuing it.
    #[must_use]
    pub fn front(&self) -> Option<u32> {
        self.entries.front().copied()
    }

    /// The number of live processes.
    #[must_use]
    pub fn len(&self) -> usize {
        self.entries.len()
    }

    /// Returns `true` if the warrior has no live processes and has lost.
    #[must_use]
    pub fn is_empty(&self) -> bool {
        self.entries.is_empty()
    }
}
```

```rust
pub mod classic_data;
pub mod classic_flow;
pub mod fields;
pub mod operand;

use crate::core::Core;
use crate::instruction::{Instruction, Opcode};
use crate::warrior::WarriorId;
use classic_data::{exec_binop, exec_mov, BinOp, StepResult};
use classic_flow::{
    exec_dat, exec_djn, exec_jmn, exec_jmp, exec_jmz, exec_nop, exec_skip_cmp, exec_spl, SkipCmp,
};
use operand::{resolve, Operands};

/// Resolves operands and executes one instruction.
///
/// This is the single dispatch point for every opcode. It contains no dialect
/// branch: extended opcodes are rejected at assembly and warrior admission, so
/// by the time an instruction reaches here it is legal.
pub fn dispatch(
    core: &mut Core,
    pc: u32,
    owner: WarriorId,
) -> StepResult {
    let instr: Instruction = core.get(pc);
    let ops: Operands = resolve(core, pc, instr, owner);
    match instr.opcode {
        Opcode::Dat => exec_dat(),
        Opcode::Nop => exec_nop(),
        Opcode::Mov => exec_mov(core, instr, ops, owner),
        Opcode::Add => exec_binop(core, instr, ops, owner, BinOp::Add),
        Opcode::Sub => exec_binop(core, instr, ops, owner, BinOp::Sub),
        Opcode::Mul => exec_binop(core, instr, ops, owner, BinOp::Mul),
        Opcode::Div => exec_binop(core, instr, ops, owner, BinOp::Div),
        Opcode::Mod => exec_binop(core, instr, ops, owner, BinOp::Mod),
        Opcode::Jmp => exec_jmp(ops),
        Opcode::Jmz => exec_jmz(instr, ops),
        Opcode::Jmn => exec_jmn(instr, ops),
        Opcode::Djn => exec_djn(core, instr, ops, owner),
        Opcode::Spl => exec_spl(ops),
        Opcode::Seq => exec_skip_cmp(instr, ops, SkipCmp::Seq),
        Opcode::Sne => exec_skip_cmp(instr, ops, SkipCmp::Sne),
        Opcode::Slt => exec_skip_cmp(instr, ops, SkipCmp::Slt),
        other => unimplemented!("extended opcode {other:?} arrives in a later task"),
    }
}
```

```rust
//! The battle simulator.

use crate::config::Config;
use crate::core::Core;
use crate::exec::classic_data::StepResult;
use crate::exec::dispatch;
use crate::instruction::Instruction;
use crate::observer::Observer;
use crate::queue::ProcessQueue;
use crate::warrior::{Warrior, WarriorId};

/// How a battle ended.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Outcome {
    /// Exactly one warrior still had live processes.
    Win(WarriorId),
    /// The cycle limit was reached with more than one warrior alive.
    Tie,
    /// Every warrior died, in the same cycle.
    Draw,
}

/// A warrior placed too close to another.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct SeparationError {
    /// Index of the first of the two warriors involved.
    pub first: usize,
    /// Index of the second.
    pub second: usize,
    /// The distance actually between them.
    pub distance: u32,
}

impl std::fmt::Display for SeparationError {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        write!(
            f,
            "warriors {} and {} are only {} cells apart",
            self.first, self.second, self.distance
        )
    }
}

impl std::error::Error for SeparationError {}

/// A running battle.
#[derive(Debug, Clone)]
pub struct Mars {
    config: Config,
    core: Core,
    warriors: Vec<Warrior>,
    queues: Vec<ProcessQueue>,
    cycle: u32,
}

impl Mars {
    /// Loads `warriors` at `positions` and prepares them to run.
    ///
    /// `positions` must have the same length as `warriors`. Use
    /// [`Mars::check_positions`] first if the caller has not already validated
    /// separation.
    ///
    /// # Panics
    /// Panics if `positions.len() != warriors.len()`.
    #[must_use]
    pub fn new(config: Config, warriors: Vec<Warrior>, positions: &[u32]) -> Self {
        assert_eq!(warriors.len(), positions.len(), "one position per warrior");
        let mut core = Core::new(&config);
        let mut queues = Vec::with_capacity(warriors.len());
        for (index, warrior) in warriors.iter().enumerate() {
            let id = WarriorId(u8::try_from(index).expect("at most 256 warriors"));
            let base = positions[index];
            for (offset, instr) in warrior.code.iter().enumerate() {
                let addr = core.fold(i64::from(base) + offset as i64);
                core.set(addr, *instr, id);
            }
            let mut queue = ProcessQueue::new(config.max_processes);
            queue.push(core.fold(i64::from(base) + i64::from(warrior.start)));
            queues.push(queue);
        }
        Self { config, core, warriors, queues, cycle: 0 }
    }

    /// Verifies that no two positions are closer than `config.min_separation`,
    /// measuring distance circularly.
    ///
    /// # Errors
    /// Returns the first violating pair.
    pub fn check_positions(config: &Config, positions: &[u32]) -> Result<(), SeparationError> {
        let size = i64::from(config.core_size);
        for i in 0..positions.len() {
            for j in (i + 1)..positions.len() {
                let raw = (i64::from(positions[j]) - i64::from(positions[i])).rem_euclid(size);
                let distance = raw.min(size - raw) as u32;
                if distance < config.min_separation {
                    return Err(SeparationError { first: i, second: j, distance });
                }
            }
        }
        Ok(())
    }

    /// The battle configuration.
    #[must_use]
    pub const fn config(&self) -> &Config {
        &self.config
    }

    /// The core, for display and inspection.
    #[must_use]
    pub const fn core(&self) -> &Core {
        &self.core
    }

    /// The loaded warriors.
    #[must_use]
    pub fn warriors(&self) -> &[Warrior] {
        &self.warriors
    }

    /// Cycles executed so far.
    #[must_use]
    pub const fn cycle(&self) -> u32 {
        self.cycle
    }

    /// The number of live processes belonging to `warrior`.
    #[must_use]
    pub fn process_count(&self, warrior: WarriorId) -> usize {
        self.queues[warrior.0 as usize].len()
    }

    /// The program counter `warrior` will execute next, if it is alive.
    #[must_use]
    pub fn process_pc(&self, warrior: WarriorId) -> Option<u32> {
        self.queues[warrior.0 as usize].front()
    }

    /// Alias of [`Mars::process_pc`], for readability at call sites.
    #[must_use]
    pub fn current_pc(&self, warrior: WarriorId) -> Option<u32> {
        self.process_pc(warrior)
    }

    /// The instruction `warrior` will execute next, if it is alive.
    #[must_use]
    pub fn current_instruction(&self, warrior: WarriorId) -> Option<Instruction> {
        self.process_pc(warrior).map(|pc| self.core.get(pc))
    }

    /// Runs one cycle: every live warrior executes one instruction, in warrior
    /// order.
    pub fn step(&mut self, observer: &mut impl Observer) {
        for index in 0..self.queues.len() {
            let id = WarriorId(index as u8);
            let Some(pc) = self.queues[index].pop() else {
                continue;
            };
            observer.on_exec(pc, id);
            let result = dispatch(&mut self.core, pc, id);
            for (addr, writer) in self.core.take_writes() {
                observer.on_write(addr, writer);
            }
            match result {
                StepResult::Continue => {
                    self.queues[index].push(self.core.fold(i64::from(pc) + 1));
                }
                StepResult::Skip => {
                    self.queues[index].push(self.core.fold(i64::from(pc) + 2));
                }
                StepResult::Jump(target) => {
                    self.queues[index].push(target);
                }
                StepResult::Split(target) => {
                    self.queues[index].push(self.core.fold(i64::from(pc) + 1));
                    self.queues[index].push(target);
                }
                StepResult::Die => {
                    observer.on_death(id, pc);
                }
            }
        }
        self.cycle += 1;
    }

    /// Returns the outcome if the battle has ended, otherwise `None`.
    #[must_use]
    pub fn outcome(&self) -> Option<Outcome> {
        let alive: Vec<WarriorId> = (0..self.queues.len())
            .filter(|i| !self.queues[*i].is_empty())
            .map(|i| WarriorId(i as u8))
            .collect();
        match alive.len() {
            0 => Some(Outcome::Draw),
            1 if self.queues.len() > 1 => Some(Outcome::Win(alive[0])),
            _ if self.cycle >= self.config.max_cycles => Some(Outcome::Tie),
            _ => None,
        }
    }

    /// Runs until the battle ends or the cycle limit is reached.
    pub fn run(&mut self, observer: &mut impl Observer) -> Outcome {
        loop {
            if let Some(outcome) = self.outcome() {
                return outcome;
            }
            self.step(observer);
        }
    }
}
```

```rust
//! Assembly errors.
//!
//! The assembler is the only CoreWarz component that reports errors to a
//! human. The VM has no runtime errors: a loaded warrior is well-formed by
//! construction.

use corewarz_core::{Modifier, Opcode};

/// What went wrong while assembling.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum AsmErrorKind {
    /// The mnemonic is not a known opcode.
    UnknownOpcode(String),
    /// This opcode does not accept this modifier.
    IllegalModifier { opcode: Opcode, modifier: Modifier },
    /// A CoreWarz extension was used under the classic dialect.
    ExtendedOpcodeInClassic(Opcode),
    /// An operand referred to a label that was never defined.
    UnresolvedLabel(String),
    /// The same label was defined twice.
    DuplicateLabel(String),
    /// The warrior exceeds `Config::max_length`.
    TooLong { length: u32, limit: u32 },
    /// An operand could not be parsed.
    MalformedOperand(String),
    /// A numeric literal could not be parsed.
    BadNumber(String),
    /// The instruction needs at least one operand and none was given.
    MissingOperand,
}

impl std::fmt::Display for AsmErrorKind {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        match self {
            Self::UnknownOpcode(s) => write!(f, "unknown opcode `{s}`"),
            Self::IllegalModifier { opcode, modifier } => {
                write!(f, "{opcode:?} does not accept the modifier {modifier:?}")
            }
            Self::ExtendedOpcodeInClassic(op) => {
                write!(f, "{op:?} is a CoreWarz extension and is illegal in classic mode")
            }
            Self::UnresolvedLabel(s) => write!(f, "undefined label `{s}`"),
            Self::DuplicateLabel(s) => write!(f, "label `{s}` is defined more than once"),
            Self::TooLong { length, limit } => {
                write!(f, "warrior is {length} instructions long, the limit is {limit}")
            }
            Self::MalformedOperand(s) => write!(f, "malformed operand `{s}`"),
            Self::BadNumber(s) => write!(f, "`{s}` is not a number"),
            Self::MissingOperand => write!(f, "missing operand"),
        }
    }
}

/// An assembly error, with the source line that caused it.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct AsmError {
    /// One-based source line number.
    pub line: usize,
    /// What went wrong.
    pub kind: AsmErrorKind,
}

impl std::fmt::Display for AsmError {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        write!(f, "line {}: {}", self.line, self.kind)
    }
}

impl std::error::Error for AsmError {}
```

```rust
use corewarz_core::{AddrMode, Modifier, Opcode};

/// The modifiers `opcode` accepts.
///
/// This is where the restricted-modifier rule for CoreWarz extensions lives:
/// `CALL`, `RET`, `PUSH`, and `POP` accept none, and the conditional branches
/// accept only the modifiers that select which field of the tested operand to
/// examine.
#[must_use]
pub const fn legal_modifiers(opcode: Opcode) -> &'static [Modifier] {
    match opcode {
        Opcode::Dat => &[F],
        Opcode::Mov | Opcode::Seq | Opcode::Sne => &[A, B, AB, BA, F, X, I],
        Opcode::Add | Opcode::Sub | Opcode::Mul | Opcode::Div | Opcode::Mod | Opcode::Slt => {
            &[A, B, AB, BA, F, X]
        }
        Opcode::Jmp | Opcode::Spl | Opcode::Nop => &[A, B, AB, BA, F, X, I],
        Opcode::Jmz | Opcode::Jmn | Opcode::Djn => &[A, B, F, X, I],
        // --- extended ---
        Opcode::And | Opcode::Or | Opcode::Xor | Opcode::Shl | Opcode::Shr | Opcode::Not
        | Opcode::Tst => &[A, B, AB, BA, F, X],
        Opcode::Jez | Opcode::Jnz | Opcode::Jlz | Opcode::Jgz => &[A, B, F, X],
        Opcode::Call | Opcode::Ret | Opcode::Push | Opcode::Pop => &[],
    }

    let a_immediate = a_mode == AddrMode::Immediate;
    let b_immediate = b_mode == AddrMode::Immediate;

        Opcode::Dat => F,
        Opcode::Mov | Opcode::Seq | Opcode::Sne | Opcode::Tst => {

                B

                I

        Some('>') => AddrMode::PostincB,

    };
```

```rust
//! Line-level tokenisation.

/// A source line split into its syntactic parts, with comments removed.
#[derive(Debug, Clone, PartialEq, Eq, Default)]
pub struct Line {
    /// One-based source line number.
    pub number: usize,
    /// The label in column one, if any.
    pub label: Option<String>,
    /// The mnemonic or pseudo-op.
    pub mnemonic: Option<String>,
    /// The modifier suffix, without the dot.
    pub modifier: Option<String>,
    /// The comma-separated operands, trimmed.
    pub operands: Vec<String>,
}

impl Line {
    /// Returns `true` if the line carries no mnemonic and no label.
    #[must_use]
    pub fn is_blank(&self) -> bool {
        self.label.is_none() && self.mnemonic.is_none()
    }
}

/// Splits `source` into [`Line`]s, stripping comments and blank lines.
///
/// A leading token is treated as a label when the line has more than one
/// token and the first token is not a known mnemonic; the caller resolves
/// that ambiguity by consulting `parse_opcode`.
#[must_use]
pub fn lex(source: &str, is_mnemonic: &dyn Fn(&str) -> bool) -> Vec<Line> {
    let mut out = Vec::new();
    for (index, raw) in source.lines().enumerate() {
        let text = raw.split(';').next().unwrap_or("").trim();
        if text.is_empty() {
            continue;
        }
        let (head, rest) = match text.split_once(char::is_whitespace) {
            Some((h, r)) => (h, r.trim()),
            None => (text, ""),
        };
        let mut line = Line { number: index + 1, ..Line::default() };
        let body = if is_mnemonic(head) {
            text
        } else {
            line.label = Some(head.to_string());
            rest
        };
        if body.is_empty() {
            out.push(line);
            continue;
        }
        let (mnemonic_part, operand_part) = match body.split_once(char::is_whitespace) {
            Some((m, o)) => (m, o.trim()),
            None => (body, ""),
        };
        let (mnemonic, modifier) = match mnemonic_part.split_once('.') {
            Some((m, md)) => (m.to_string(), Some(md.to_string())),
            None => (mnemonic_part.to_string(), None),
        };
        line.mnemonic = Some(mnemonic);
        line.modifier = modifier;
        if !operand_part.is_empty() {
            line.operands = operand_part
                .split(',')
                .map(|s| s.trim().to_string())
                .filter(|s| !s.is_empty())
                .collect();
        }
        out.push(line);
    }
    out
}
```

```rust
//! Operand parsing: an addressing-mode sigil followed by a label-or-number
//! expression of the form `term [+|- integer]`.

use crate::error::AsmErrorKind;
use crate::modifier::parse_mode;
use corewarz_core::AddrMode;

/// An operand before label resolution.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct RawOperand {
    /// The addressing mode.
    pub mode: AddrMode,
    /// A label the value is relative to, if the expression names one.
    pub label: Option<String>,
    /// The literal offset added to the label, or the whole value when there is
    /// no label.
    pub offset: i64,
}

impl RawOperand {
    /// The operand an omitted second operand assumes: `$0`.
    #[must_use]
    pub const fn direct_zero() -> Self {
        Self { mode: AddrMode::Direct, label: None, offset: 0 }
    }
}

/// Parses one operand.
///
/// # Errors
/// Returns [`AsmErrorKind::MalformedOperand`] for an unrecognised sigil or an
/// empty expression, and [`AsmErrorKind::BadNumber`] for an unparseable
/// integer.
pub fn parse_operand(text: &str) -> Result<RawOperand, AsmErrorKind> {
    let text = text.trim();
    if text.is_empty() {
        return Err(AsmErrorKind::MalformedOperand(text.to_string()));
    }
    let first = text.chars().next().expect("non-empty");
    let (mode, expr) = if first.is_alphanumeric() || first == '-' || first == '_' {
        (AddrMode::Direct, text)
    } else {
        let mode = parse_mode(Some(first))
            .ok_or_else(|| AsmErrorKind::MalformedOperand(text.to_string()))?;
        (mode, text[first.len_utf8()..].trim())
    };
    if expr.is_empty() {
        return Err(AsmErrorKind::MalformedOperand(text.to_string()));
    }

    // Split off a trailing `+ n` or `- n`, ignoring a leading sign.
    let bytes: Vec<char> = expr.chars().collect();
    let mut split = None;
    for i in (1..bytes.len()).rev() {
        if bytes[i] == '+' || bytes[i] == '-' {
            split = Some(i);
            break;
        }
    }

    let (term, adjust) = match split {
        Some(i) => {
            let head: String = bytes[..i].iter().collect();
            let tail: String = bytes[i..].iter().collect();
            let n: i64 = tail
                .replace(' ', "")
                .parse()
                .map_err(|_| AsmErrorKind::BadNumber(tail.clone()))?;
            (head.trim().to_string(), n)
        }
        None => (expr.to_string(), 0),
    };

    if let Ok(n) = term.parse::<i64>() {
        return Ok(RawOperand { mode, label: None, offset: n + adjust });
    }
    if term.chars().next().is_some_and(|c| c.is_ascii_digit()) {
        return Err(AsmErrorKind::BadNumber(term));
    }
    Ok(RawOperand { mode, label: Some(term), offset: adjust })
}
```

```rust
//! Two-pass assembly: collect labels and `EQU`s, then emit instructions.

use std::collections::HashMap;

use corewarz_core::{Config, Dialect, Instruction, Modifier, Opcode, Warrior};

use crate::error::{AsmError, AsmErrorKind};
use crate::lexer::{lex, Line};
use crate::modifier::{default_modifier, legal_modifiers, parse_modifier, parse_opcode};
use crate::parser::{parse_operand, RawOperand};

fn is_pseudo(text: &str) -> bool {
    matches!(text.to_ascii_uppercase().as_str(), "EQU" | "ORG" | "END")
}

/// Assembles Redcode `source` into a loadable warrior.
///
/// # Errors
/// Returns the first [`AsmError`], carrying the offending source line.
pub fn assemble(source: &str, config: &Config) -> Result<Warrior, AsmError> {
    let is_mnemonic = |t: &str| parse_opcode(t.split('.').next().unwrap_or(t)).is_some() || is_pseudo(t);
    let lines = lex(source, &is_mnemonic);

    // --- pass one: labels, EQUs, ORG ---
    let mut labels: HashMap<String, i64> = HashMap::new();
    let mut equs: HashMap<String, String> = HashMap::new();
    let mut org: Option<String> = None;
    let mut offset: i64 = 0;
    for line in &lines {
        let mnemonic = line.mnemonic.as_deref().unwrap_or("").to_ascii_uppercase();
        match mnemonic.as_str() {
            "EQU" => {
                let name = line.label.clone().ok_or(AsmError {
                    line: line.number,
                    kind: AsmErrorKind::MissingOperand,
                })?;
                let value = line.operands.first().cloned().ok_or(AsmError {
                    line: line.number,
                    kind: AsmErrorKind::MissingOperand,
                })?;
                equs.insert(name.to_ascii_lowercase(), value);
            }
            "ORG" | "END" => {
                if let Some(target) = line.operands.first() {
                    org = Some(target.clone());
                }
            }
            "" => {
                if let Some(label) = &line.label {
                    insert_label(&mut labels, label, offset, line.number)?;
                }
            }
            _ => {
                if let Some(label) = &line.label {
                    insert_label(&mut labels, label, offset, line.number)?;
                }
                offset += 1;
            }
        }
    }

    let length = u32::try_from(offset).unwrap_or(u32::MAX);
    if length > config.max_length {
        let line = lines.last().map_or(1, |l| l.number);
        return Err(AsmError {
            line,
            kind: AsmErrorKind::TooLong { length, limit: config.max_length },
        });
    }

    // --- pass two: emit ---
    let mut code = Vec::with_capacity(offset as usize);
    let mut address: i64 = 0;
    for line in &lines {
        let Some(raw_mnemonic) = &line.mnemonic else {
            continue;
        };
        if is_pseudo(raw_mnemonic) {
            continue;
        }
        let instr = emit(line, raw_mnemonic, address, &labels, &equs, config)?;
        code.push(instr);
        address += 1;
    }

    let start = match org {
        Some(target) => {
            let resolved = resolve_expr(&target, 0, &labels, &equs).map_err(|kind| AsmError {
                line: 1,
                kind,
            })?;
            u32::try_from(resolved.rem_euclid(i64::from(config.core_size))).unwrap_or(0)
        }
        None => 0,
    };

    Ok(Warrior { name: String::from("warrior"), code, start })
}

fn insert_label(
    labels: &mut HashMap<String, i64>,
    label: &str,
    offset: i64,
    line: usize,
) -> Result<(), AsmError> {
    let key = label.to_ascii_lowercase();
    if labels.insert(key, offset).is_some() {
        return Err(AsmError { line, kind: AsmErrorKind::DuplicateLabel(label.to_string()) });
    }
    Ok(())
}

/// Resolves an operand expression to a value relative to `address`.
fn resolve_expr(
    text: &str,
    address: i64,
    labels: &HashMap<String, i64>,
    equs: &HashMap<String, String>,
) -> Result<i64, AsmErrorKind> {
    let operand = parse_operand(text)?;
    resolve_operand(&operand, address, labels, equs).map(|(_, v)| v)
}

fn resolve_operand(
    operand: &RawOperand,
    address: i64,
    labels: &HashMap<String, i64>,
    equs: &HashMap<String, String>,
) -> Result<(corewarz_core::AddrMode, i64), AsmErrorKind> {
    let Some(label) = &operand.label else {
        return Ok((operand.mode, operand.offset));
    };
    let key = label.to_ascii_lowercase();
    if let Some(target) = labels.get(&key) {
        return Ok((operand.mode, target - address + operand.offset));
    }
    if let Some(text) = equs.get(&key) {
        let inner = parse_operand(text)?;
        let (_, value) = resolve_operand(&inner, address, labels, equs)?;
        return Ok((operand.mode, value + operand.offset));
    }
    Err(AsmErrorKind::UnresolvedLabel(label.clone()))
}

fn emit(
    line: &Line,
    raw_mnemonic: &str,
    address: i64,
    labels: &HashMap<String, i64>,
    equs: &HashMap<String, String>,
    config: &Config,
) -> Result<Instruction, AsmError> {
    let at = |kind: AsmErrorKind| AsmError { line: line.number, kind };

    let opcode = parse_opcode(raw_mnemonic)
        .ok_or_else(|| at(AsmErrorKind::UnknownOpcode(raw_mnemonic.to_string())))?;

    if config.dialect == Dialect::Classic && opcode.is_extended() {
        return Err(at(AsmErrorKind::ExtendedOpcodeInClassic(opcode)));
    }

    let explicit_modifier = match &line.modifier {
        Some(text) => Some(
            parse_modifier(text)
                .ok_or_else(|| at(AsmErrorKind::MalformedOperand(text.clone())))?,
        ),
        None => None,
    };

    let mut operands = Vec::new();
    for text in &line.operands {
        operands.push(parse_operand(text).map_err(at)?);
    }
    if operands.is_empty() {
        if opcode == Opcode::Dat || opcode == Opcode::Nop || opcode == Opcode::Ret {
            operands.push(RawOperand::direct_zero());
        } else {
            return Err(at(AsmErrorKind::MissingOperand));
        }
    }
    while operands.len() < 2 {
        operands.push(RawOperand::direct_zero());
    }

    let (a_mode, a_value) = resolve_operand(&operands[0], address, labels, equs).map_err(at)?;
    let (b_mode, b_value) = resolve_operand(&operands[1], address, labels, equs).map_err(at)?;

    let modifier = match explicit_modifier {
        Some(m) => {
            if !legal_modifiers(opcode).contains(&m) {
                return Err(at(AsmErrorKind::IllegalModifier { opcode, modifier: m }));
            }
            m
        }
        None => default_modifier(opcode, a_mode, b_mode),
    };

    let size = i64::from(config.core_size);
    Ok(Instruction {
        opcode,
        modifier,
        a_mode,
        a: a_value.rem_euclid(size) as u32,
        b_mode,
        b: b_value.rem_euclid(size) as u32,
    })
}
```

```rust
/// Renders one instruction as canonical Redcode.
///
/// Opcodes that accept no modifier are printed without one, so that the text
/// reassembles cleanly.
#[must_use]
pub fn disassemble_instruction(instr: Instruction) -> String {
    let suffix = if crate::modifier::legal_modifiers(instr.opcode).is_empty() {
        String::new()
    } else {
        format!(".{}", modifier_name(instr.modifier))
    };
    format!(
        "{}{} {}{}, {}{}",
        opcode_name(instr.opcode),
        suffix,
        mode_sigil(instr.a_mode),
        instr.a,
        mode_sigil(instr.b_mode),
        instr.b
    )
}

/// Renders a whole warrior, one instruction per line.
#[must_use]
pub fn disassemble(warrior: &Warrior) -> String {
    let mut out = String::new();
    if warrior.start != 0 {
        out.push_str(&format!("ORG {}\n", warrior.start));
    }
    for instr in &warrior.code {
        out.push_str(&disassemble_instruction(*instr));
        out.push('\n');
    }
    out
}
```

```rust
//! Extended bitwise opcodes.
//!
//! These behave exactly as [`crate::exec::classic_data::exec_binop`] does,
//! sharing the same operand evaluation and the same modifier table. Only the
//! arithmetic differs.

use crate::core::Core;
use crate::exec::classic_data::StepResult;
use crate::exec::fields::field_pairs;
use crate::exec::operand::Operands;
use crate::instruction::Instruction;
use crate::warrior::WarriorId;

/// Number of bits in a shift operand's word.
const WORD_BITS: u32 = 32;

/// An extended bitwise operation.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum BitOp {
    And,
    Or,
    Xor,
    Shl,
    Shr,
    /// Complements the destination field. The source value is ignored.
    Not,
}

/// Executes `AND`, `OR`, `XOR`, `SHL`, `SHR`, or `NOT`.
pub fn exec_bitop(
    core: &mut Core,
    instr: Instruction,
    ops: Operands,
    owner: WarriorId,
    op: BitOp,
) -> StepResult {
    let mut dst = core.get(ops.b_ptr);
    for (src_f, dst_f) in field_pairs(instr.modifier) {
        let s = src_f.get(&ops.ira);
        let d = dst_f.get(&ops.irb);
        let raw: u64 = match op {
            BitOp::And => u64::from(d & s),
            BitOp::Or => u64::from(d | s),
            BitOp::Xor => u64::from(d ^ s),
            BitOp::Not => u64::from(!d),
            BitOp::Shl => {
                if s >= WORD_BITS {
                    0
                } else {
                    u64::from(d) << s
                }
            }
            BitOp::Shr => {
                if s >= WORD_BITS {
                    0
                } else {
                    u64::from(d >> s)
                }
            }
        };
        dst_f.set(&mut dst, core.fold(raw as i64));
    }
    core.set(ops.b_ptr, dst, owner);
    StepResult::Continue
}
```

```rust
//!

//! core, which is what makes the extended conditional branches sufficient: any
//! comparison-branch is `TST` followed by one branch.

use crate::exec::classic_data::StepResult;
use crate::exec::fields::field_pairs;
use crate::exec::operand::Operands;
use crate::instruction::Instruction;
use crate::warrior::WarriorId;

/// Executes `TST`.
///
/// Writes `0` when the compared fields are equal, `1` when the source field is
/// greater, and −1 (`CORESIZE-1`) when it is smaller.
pub fn exec_tst(
    core: &mut Core,
    instr: Instruction,
    ops: Operands,
    owner: WarriorId,
) -> StepResult {
    let mut dst = core.get(ops.b_ptr);
    for (src_f, dst_f) in field_pairs(instr.modifier) {
        let s = src_f.get(&ops.ira);
        let d = dst_f.get(&ops.irb);
        let value = match s.cmp(&d) {
            std::cmp::Ordering::Equal => 0,
            std::cmp::Ordering::Greater => 1,
            std::cmp::Ordering::Less => core.negative_one(),
        };
        dst_f.set(&mut dst, value);
    }
    core.set(ops.b_ptr, dst, owner);
    StepResult::Continue
}
```

```rust
//! Extended conditional branches.
//!
//! Each branch tests the B-operand against zero and jumps to the A-operand.
//! Testing against zero rather than comparing two operands is what keeps these
//! instructions to two operands; [`crate::exec::ext_compare::exec_tst`] makes
//! that sufficient.

use crate::core::Core;
use crate::exec::classic_data::StepResult;
use crate::exec::operand::Operands;
use crate::instruction::{Instruction, Modifier};

/// An extended conditional branch.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Branch {
    /// Jump if zero.
    Jez,
    /// Jump if non-zero.
    Jnz,
    /// Jump if negative under the signed reading.
    Jlz,
    /// Jump if positive under the signed reading.
    Jgz,
}

/// Executes `JEZ`, `JNZ`, `JLZ`, or `JGZ`.
///
/// Under `.F` and `.X` the condition must hold for both fields. The assembler
/// rejects `.AB`, `.BA`, and `.I` on these opcodes, so those modifiers cannot
/// reach here; they are treated as `.F` defensively.
#[must_use]
pub fn exec_branch(
    core: &Core,
    instr: Instruction,
    ops: Operands,
    branch: Branch,
) -> StepResult {
    let values: &[u32] = match instr.modifier {
        Modifier::A => &[ops.irb.a],
        Modifier::B => &[ops.irb.b],
        _ => &[ops.irb.a, ops.irb.b],
    };
    let holds = |v: u32| match branch {
        Branch::Jez => v == 0,
        Branch::Jnz => v != 0,
        Branch::Jlz => core.is_negative(v),
        Branch::Jgz => core.is_positive(v),
    };
    if values.iter().copied().all(holds) {
        StepResult::Jump(ops.a_ptr)
    } else {
        StepResult::Continue
    }
}
```

```rust
        Opcode::Jlz => exec_branch(core, instr, ops, Branch::Jlz),
```

### Task 12: Core-resident subroutines

**Files:**
- Create: `crates/corewarz-core/src/exec/ext_stack.rs`
- Modify: `crates/corewarz-core/src/exec/mod.rs`

**Interfaces:**
- Consumes: `Operands`, `StepResult`, `Core` (Tasks 3–5).
- Produces: `exec_call`, `exec_ret`, `exec_push`, `exec_pop`.

The stack lives entirely in the core, so it is attackable — the point of the design. Definitions, exactly:

- A **stack-pointer cell** is the cell the second operand (for `RET`, the first operand) resolves to. Its **B-field** holds the current stack pointer, a folded absolute address.
- `CALL target, sp` — write the return address (`pc + 1`, folded) into the **B-field** of the cell at the stack pointer, advance the pointer by 1, then jump to `target`.
- `RET sp` — retreat the pointer by 1, read the **B-field** of the cell there, jump to it.
- `PUSH val, sp` — write the A-operand's resolved **address** into the B-field at the stack pointer, advance the pointer.
- `POP dst, sp` — retreat the pointer, read the B-field there, write it into the **B-field** of the A-operand's cell.

The stack grows upward and wraps like all core arithmetic. These opcodes take no modifier. A `RET` through a bombed pointer simply jumps somewhere, usually fatally: there is no new failure mode.

```rust
//! Core-resident subroutines.
//!
//! The stack lives in the core and is therefore fully attackable: bombing a
//! stack-pointer cell redirects the victim's next `RET`, and the stack itself
//! can be read, corrupted, or overwritten with a chosen return address. This
//! is deliberate. No process has private state.
//!
//! A *stack-pointer cell* holds the current stack pointer in its B-field. The
//! stack grows upward and wraps like all core arithmetic.

use crate::core::Core;
use crate::exec::classic_data::StepResult;
use crate::exec::operand::Operands;
use crate::warrior::WarriorId;

/// Reads the stack pointer out of the cell at `sp_cell`.
fn load_sp(core: &Core, sp_cell: u32) -> u32 {
    core.get(sp_cell).b
}

/// Writes `value` back into the stack-pointer cell at `sp_cell`.
fn store_sp(core: &mut Core, sp_cell: u32, value: u32, owner: WarriorId) {
    let mut cell = core.get(sp_cell);
    cell.b = value;
    core.set(sp_cell, cell, owner);
}

/// Writes `value` into the B-field of the cell at `addr`.
fn store_b(core: &mut Core, addr: u32, value: u32, owner: WarriorId) {
    let mut cell = core.get(addr);
    cell.b = value;
    core.set(addr, cell, owner);
}

/// Executes `CALL target, sp`.
///
/// Pushes `pc + 1` onto the stack, advances the stack pointer, and jumps to
/// the A-operand.
pub fn exec_call(core: &mut Core, pc: u32, ops: Operands, owner: WarriorId) -> StepResult {
    let sp_cell = ops.b_ptr;
    let sp = load_sp(core, sp_cell);
    let return_address = core.fold(i64::from(pc) + 1);
    store_b(core, sp, return_address, owner);
    store_sp(core, sp_cell, core.fold(i64::from(sp) + 1), owner);
    StepResult::Jump(ops.a_ptr)
}

/// Executes `RET sp`.
///
/// Retreats the stack pointer and jumps to the address stored there. A
/// corrupted pointer or a corrupted stack simply sends the process somewhere
/// else; there is no error condition.
pub fn exec_ret(core: &mut Core, ops: Operands, owner: WarriorId) -> StepResult {
    let sp_cell = ops.a_ptr;
    let sp = core.fold(i64::from(load_sp(core, sp_cell)) - 1);
    store_sp(core, sp_cell, sp, owner);
    let target = core.get(sp).b;
    StepResult::Jump(target)
}

/// Executes `PUSH val, sp`.
///
/// Pushes the A-operand's resolved address and advances the stack pointer.
pub fn exec_push(core: &mut Core, ops: Operands, owner: WarriorId) -> StepResult {
    let sp_cell = ops.b_ptr;
    let sp = load_sp(core, sp_cell);
    store_b(core, sp, ops.ira.b, owner);
    store_sp(core, sp_cell, core.fold(i64::from(sp) + 1), owner);
    StepResult::Continue
}

/// Executes `POP dst, sp`.
///
/// Retreats the stack pointer and writes the value there into the B-field of
/// the A-operand's cell.
pub fn exec_pop(core: &mut Core, ops: Operands, owner: WarriorId) -> StepResult {
    let sp_cell = ops.b_ptr;
    let sp = core.fold(i64::from(load_sp(core, sp_cell)) - 1);
    store_sp(core, sp_cell, sp, owner);
    let value = core.get(sp).b;
    store_b(core, ops.a_ptr, value, owner);
    StepResult::Continue
}
```

```rust
/// Why a set of warriors could not be admitted to a battle.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum AdmissionError {
    /// Two warriors were placed too close together.
    Separation(SeparationError),
    /// A warrior contains a CoreWarz extension under the classic dialect.
    ExtendedOpcode {
        /// Index of the offending warrior.
        warrior: usize,
        /// Offset of the offending instruction within that warrior.
        offset: usize,
        /// The offending opcode.
        opcode: crate::instruction::Opcode,
    },
    /// A warrior is longer than `Config::max_length`.
    TooLong { warrior: usize, length: u32, limit: u32 },
}

impl std::fmt::Display for AdmissionError {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        match self {
            Self::Separation(e) => write!(f, "{e}"),
            Self::ExtendedOpcode { warrior, offset, opcode } => write!(
                f,
                "warrior {warrior} instruction {offset}: {opcode:?} is a CoreWarz extension \
                 and is illegal in classic mode"
            ),
            Self::TooLong { warrior, length, limit } => {
                write!(f, "warrior {warrior} is {length} instructions long, the limit is {limit}")
            }
        }
    }
}

impl std::error::Error for AdmissionError {}
```

```rust
    /// Validates `warriors` against `config` and loads them at `positions`.
    ///
    /// This is the second of the two dialect chokepoints: the assembler
    /// rejects extended opcodes in source, and this rejects them in any
    /// warrior that reached the VM by another route. The interpreter's hot
    /// loop therefore contains no dialect branch.
    ///
    /// # Errors
    /// Returns the first [`AdmissionError`] found.
    ///
    /// # Panics
    /// Panics if `positions.len() != warriors.len()`.
    pub fn try_new(
        config: Config,
        warriors: Vec<Warrior>,
        positions: &[u32],
    ) -> Result<Self, AdmissionError> {
        assert_eq!(warriors.len(), positions.len(), "one position per warrior");
        Self::check_positions(&config, positions).map_err(AdmissionError::Separation)?;
        for (index, warrior) in warriors.iter().enumerate() {
            let length = u32::try_from(warrior.code.len()).unwrap_or(u32::MAX);
            if length > config.max_length {
                return Err(AdmissionError::TooLong {
                    warrior: index,
                    length,
                    limit: config.max_length,
                });
            }
            if config.dialect == crate::config::Dialect::Classic {
                for (offset, instr) in warrior.code.iter().enumerate() {
                    if instr.opcode.is_extended() {
                        return Err(AdmissionError::ExtendedOpcode {
                            warrior: index,
                            offset,
                            opcode: instr.opcode,
                        });
                    }
                }
            }
        }
        Ok(Self::new(config, warriors, positions))
    }
```

```rust
//! Running battles and placing warriors.

use corewarz_core::mars::AdmissionError;
use corewarz_core::{Config, Mars, NullObserver, Outcome, Warrior};

/// A deterministic 64-bit pseudo-random generator (SplitMix64).
///
/// Battles must be reproducible from a seed, so the CLI never uses system
/// randomness.
pub struct Rng(u64);

impl Rng {
    /// Creates a generator from `seed`.
    #[must_use]
    pub const fn new(seed: u64) -> Self {
        Self(seed)
    }

    /// Returns the next value.
    pub fn next_u64(&mut self) -> u64 {
        self.0 = self.0.wrapping_add(0x9E37_79B9_7F4A_7C15);
        let mut z = self.0;
        z = (z ^ (z >> 30)).wrapping_mul(0xBF58_476D_1CE4_E5B9);
        z = (z ^ (z >> 27)).wrapping_mul(0x94D0_49BB_1331_11EB);
        z ^ (z >> 31)
    }
}

/// Places `count` warriors, the first at 0 and the rest at pseudo-random
/// positions respecting `config.min_separation`.
///
/// Placement is a rejection sample; with the default configuration it
/// terminates quickly. After 10,000 failed attempts it falls back to even
/// spacing, which always satisfies the separation rule for any sane
/// configuration.
#[must_use]
pub fn random_positions(config: &Config, count: usize, seed: u64) -> Vec<u32> {
    let mut rng = Rng::new(seed);
    let mut positions = vec![0u32];
    for _ in 1..count {
        let mut placed = None;
        for _ in 0..10_000 {
            let candidate = u32::try_from(rng.next_u64() % u64::from(config.core_size))
                .expect("core size fits in u32");
            let mut trial = positions.clone();
            trial.push(candidate);
            if Mars::check_positions(config, &trial).is_ok() {
                placed = Some(candidate);
                break;
            }
        }
        let next = placed.unwrap_or_else(|| {
            let step = config.core_size / u32::try_from(count).unwrap_or(1).max(1);
            step * u32::try_from(positions.len()).unwrap_or(1)
        });
        positions.push(next);
    }
    positions
}

/// Runs a single battle to completion.
///
/// # Errors
/// Returns an [`AdmissionError`] if the warriors cannot be admitted.
pub fn run_battle(
    warriors: &[Warrior],
    config: &Config,
    positions: &[u32],
) -> Result<Outcome, AdmissionError> {
    let mut mars = Mars::try_new(*config, warriors.to_vec(), positions)?;
    Ok(mars.run(&mut NullObserver))
}
```

```rust
//! The `corewarz` command-line interface.

mod battle;

use std::path::{Path, PathBuf};
use std::process::ExitCode;

use clap::{Args, Parser, Subcommand};
use corewarz_asm::assemble;
use corewarz_core::{Config, Dialect, Outcome, Warrior, WarriorId};

#[derive(Parser)]
#[command(name = "corewarz", about = "An extended Core War", version)]
struct Cli {
    #[command(subcommand)]
    command: Command,
}

#[derive(Subcommand)]
enum Command {
    /// Run one or more battles headlessly and report the results.
    Run(RunArgs),
}

#[derive(Args, Clone)]
struct RunArgs {
    /// Redcode source files, one per warrior.
    #[arg(required = true)]
    warriors: Vec<PathBuf>,

    /// Number of cells in the core.
    #[arg(long, default_value_t = 8000)]
    core_size: u32,

    /// Cycles before an undecided battle is a tie.
    #[arg(long = "cycles", default_value_t = 80_000)]
    max_cycles: u32,

    /// Maximum simultaneous processes per warrior.
    #[arg(long, default_value_t = 8000)]
    max_processes: u32,

    /// Maximum instructions in a warrior.
    #[arg(long, default_value_t = 100)]
    max_length: u32,

    /// Minimum distance between two warriors.
    #[arg(long, default_value_t = 100)]
    min_separation: u32,

    /// Accept the CoreWarz extended dialect.
    #[arg(long)]
    extended: bool,

    /// Number of rounds to fight.
    #[arg(long, default_value_t = 1)]
    rounds: u32,

    /// Seed for warrior placement. The same seed reproduces the same battles.
    #[arg(long, default_value_t = 0)]
    seed: u64,

    /// Explicit comma-separated load addresses, one per warrior.
    #[arg(long, value_delimiter = ',')]
    positions: Option<Vec<u32>>,
}

impl RunArgs {
    fn config(&self) -> Config {
        Config {
            core_size: self.core_size,
            max_cycles: self.max_cycles,
            max_processes: self.max_processes,
            max_length: self.max_length,
            min_separation: self.min_separation,
            dialect: if self.extended { Dialect::Extended } else { Dialect::Classic },
        }
    }
}

fn warrior_name(path: &Path) -> String {
    path.file_stem().map_or_else(|| "warrior".to_string(), |s| s.to_string_lossy().into_owned())
}

fn load(path: &Path, config: &Config) -> Result<Warrior, String> {
    let source = std::fs::read_to_string(path)
        .map_err(|e| format!("{}: {e}", path.display()))?;
    let mut warrior =
        assemble(&source, config).map_err(|e| format!("{}: {e}", path.display()))?;
    warrior.name = warrior_name(path);
    Ok(warrior)
}

fn run(args: &RunArgs) -> Result<(), String> {
    let config = args.config();
    let mut warriors = Vec::with_capacity(args.warriors.len());
    for path in &args.warriors {
        warriors.push(load(path, &config)?);
    }

    let mut wins = vec![0u32; warriors.len()];
    let mut ties = 0u32;
    let mut draws = 0u32;

    for round in 0..args.rounds {
        let positions = match &args.positions {
            Some(explicit) => {
                if explicit.len() != warriors.len() {
                    return Err(format!(
                        "got {} positions for {} warriors",
                        explicit.len(),
                        warriors.len()
                    ));
                }
                explicit.clone()
            }
            None => battle::random_positions(
                &config,
                warriors.len(),
                args.seed.wrapping_add(u64::from(round)),
            ),
        };
        match battle::run_battle(&warriors, &config, &positions).map_err(|e| e.to_string())? {
            Outcome::Win(WarriorId(id)) => wins[id as usize] += 1,
            Outcome::Tie => ties += 1,
            Outcome::Draw => draws += 1,
        }
    }

    for (index, warrior) in warriors.iter().enumerate() {
        println!("{:<20} wins {}", warrior.name, wins[index]);
    }
    println!("{:<20} {ties}", "ties");
    println!("{:<20} {draws}", "draws");
    Ok(())
}

fn main() -> ExitCode {
    let cli = Cli::parse();
    let result = match &cli.command {
        Command::Run(args) => run(args),
    };
    match result {
        Ok(()) => ExitCode::SUCCESS,
        Err(message) => {
            eprintln!("error: {message}");
            ExitCode::FAILURE
        }
    }
}
```

```rust
//! [`VisualState`] implements [`Observer`] and holds everything the renderer
//! needs that the VM does not itself track. It contains no terminal code and
//! is fully testable without one.

use std::collections::HashMap;

use corewarz_core::{Observer, WarriorId};

/// How much heat a cell loses per rendered frame.
const DECAY_STEP: u8 = 16;

/// Per-cell activity and per-warrior positions, for rendering.
#[derive(Debug, Clone)]
pub struct VisualState {
    heat: Vec<u8>,
    exec: HashMap<WarriorId, u32>,
    deaths: HashMap<WarriorId, u32>,
}

impl VisualState {
    /// Creates state for a core of `core_size` cells.
    #[must_use]
    pub fn new(core_size: u32) -> Self {
        Self {
            heat: vec![0; core_size as usize],
            exec: HashMap::new(),
            deaths: HashMap::new(),
        }
    }

    /// How recently `addr` was written, from 0 (cold) to 255 (just written).
    #[must_use]
    pub fn heat(&self, addr: u32) -> u8 {
        self.heat[addr as usize]
    }

    /// Cools every cell by one step. Call once per rendered frame.
    pub fn decay(&mut self) {
        for h in &mut self.heat {
            *h = h.saturating_sub(DECAY_STEP);
        }
    }

    /// The address `warrior` most recently executed.
    #[must_use]
    pub fn exec_position(&self, warrior: WarriorId) -> Option<u32> {
        self.exec.get(&warrior).copied()
    }

    /// How many of `warrior`'s processes have died.
    #[must_use]
    pub fn deaths(&self, warrior: WarriorId) -> u32 {
        self.deaths.get(&warrior).copied().unwrap_or(0)
    }

    /// How many core cells each rendered character must represent so that a
    /// core of `core_size` fits into `available` characters.
    ///
    /// Rounds up, so no cell is ever left off the display.
    #[must_use]
    pub const fn cells_per_cell(core_size: u32, available: u32) -> u32 {
        if available == 0 {
            return 1;
        }
        core_size.div_ceil(available)
    }
}

impl Observer for VisualState {
    fn on_write(&mut self, addr: u32, _warrior: WarriorId) {
        self.heat[addr as usize] = u8::MAX;
    }

    fn on_exec(&mut self, addr: u32, warrior: WarriorId) {
        self.exec.insert(warrior, addr);
    }

    fn on_death(&mut self, warrior: WarriorId, _addr: u32) {
        *self.deaths.entry(warrior).or_insert(0) += 1;
    }
}
```

```rust
//! Drawing a battle.
//!
//! [`render`] is a pure function of the battle and the display state onto a
//! frame. It never mutates either, and it never touches the terminal directly.

use corewarz_asm::disassemble_instruction;
use corewarz_core::{Mars, WarriorId};
use ratatui::layout::{Constraint, Direction, Layout, Rect};
use ratatui::style::{Color, Modifier as TextModifier, Style};
use ratatui::text::{Line, Span};
use ratatui::widgets::{Block, Borders, Paragraph};
use ratatui::Frame;

use crate::state::VisualState;

/// The colour assigned to each warrior, by index.
const WARRIOR_COLORS: [Color; 6] = [
    Color::Cyan,
    Color::Magenta,
    Color::Green,
    Color::Yellow,
    Color::Blue,
    Color::Red,
];

/// The display colour for `warrior`.
#[must_use]
pub fn warrior_color(warrior: WarriorId) -> Color {
    WARRIOR_COLORS[warrior.0 as usize % WARRIOR_COLORS.len()]
}

/// Draws the whole interface.
pub fn render(frame: &mut Frame, mars: &Mars, state: &VisualState) {
    let areas = Layout::default()
        .direction(Direction::Vertical)
        .constraints([Constraint::Min(10), Constraint::Length(8), Constraint::Length(3)])
        .split(frame.area());
    render_core(frame, areas[0], mars, state);
    render_sources(frame, areas[1], mars);
    render_status(frame, areas[2], mars, state);
}

fn render_core(frame: &mut Frame, area: Rect, mars: &Mars, state: &VisualState) {
    let block = Block::default().borders(Borders::ALL).title(" core ");
    let inner = block.inner(area);
    frame.render_widget(block, area);

    let width = u32::from(inner.width).max(1);
    let height = u32::from(inner.height).max(1);
    let capacity = width * height;
    let per_char = VisualState::cells_per_cell(mars.core().size(), capacity);

    let mut lines = Vec::with_capacity(height as usize);
    for row in 0..height {
        let mut spans = Vec::with_capacity(width as usize);
        for column in 0..width {
            let first = (row * width + column) * per_char;
            if first >= mars.core().size() {
                spans.push(Span::raw(" "));
                continue;
            }
            // A run is drawn with the colour of its owner and the heat of its
            // hottest cell, so activity is never lost to aggregation.
            let mut owner = None;
            let mut heat = 0u8;
            let mut executing = false;
            for offset in 0..per_char {
                let addr = first + offset;
                if addr >= mars.core().size() {
                    break;
                }
                owner = mars.core().owner(addr).or(owner);
                heat = heat.max(state.heat(addr));
                executing |= (0..mars.warriors().len())
                    .any(|i| state.exec_position(WarriorId(i as u8)) == Some(addr));
            }
            spans.push(cell_span(owner, heat, executing));
        }
        lines.push(Line::from(spans));
    }
    frame.render_widget(Paragraph::new(lines), inner);
}

fn cell_span(owner: Option<WarriorId>, heat: u8, executing: bool) -> Span<'static> {
    let (glyph, color) = match owner {
        None => (if heat > 0 { "·" } else { " " }, Color::DarkGray),
        Some(w) => (if heat > 128 { "█" } else { "▓" }, warrior_color(w)),
    };
    let mut style = Style::default().fg(color);
    if executing {
        style = style.add_modifier(TextModifier::REVERSED);
    }
    Span::styled(glyph, style)
}

fn render_sources(frame: &mut Frame, area: Rect, mars: &Mars) {
    let block = Block::default().borders(Borders::ALL).title(" execution ");
    let inner = block.inner(area);
    frame.render_widget(block, area);

    let mut lines = Vec::new();
    for (index, warrior) in mars.warriors().iter().enumerate() {
        let id = WarriorId(index as u8);
        let color = warrior_color(id);
        match mars.process_pc(id) {
            None => lines.push(Line::from(Span::styled(
                format!("{:<12} dead", warrior.name),
                Style::default().fg(color),
            ))),
            Some(pc) => {
                // Two cells of context either side of the program counter.
                for delta in -2i64..=2 {
                    let addr = mars.core().fold(i64::from(pc) + delta);
                    let text = format!(
                        "{:<12} {addr:>5}  {}",
                        if delta == 0 { warrior.name.as_str() } else { "" },
                        disassemble_instruction(mars.core().get(addr))
                    );
                    let mut style = Style::default().fg(color);
                    if delta == 0 {
                        style = style.add_modifier(TextModifier::BOLD);
                    }
                    lines.push(Line::from(Span::styled(text, style)));
                }
            }
        }
    }
    frame.render_widget(Paragraph::new(lines), inner);
}

fn render_status(frame: &mut Frame, area: Rect, mars: &Mars, state: &VisualState) {
    let mut spans = vec![Span::raw(format!("cycle {:>7}   ", mars.cycle()))];
    for (index, warrior) in mars.warriors().iter().enumerate() {
        let id = WarriorId(index as u8);
        spans.push(Span::styled(
            format!(
                "{}: {} proc / {} dead   ",
                warrior.name,
                mars.process_count(id),
                state.deaths(id)
            ),
            Style::default().fg(warrior_color(id)),
        ));
    }
    let block = Block::default().borders(Borders::ALL).title(" status ");
    frame.render_widget(Paragraph::new(Line::from(spans)).block(block), area);
}
```

```rust
//! The terminal application: event loop, speed control, and stepping.

use std::io;
use std::time::{Duration, Instant};

use corewarz_core::{Mars, Outcome};
use crossterm::event::{self, Event, KeyCode, KeyEventKind};
use crossterm::terminal::{disable_raw_mode, enable_raw_mode, EnterAlternateScreen, LeaveAlternateScreen};
use crossterm::ExecutableCommand;
use ratatui::backend::CrosstermBackend;
use ratatui::Terminal;

use crate::render::render;
use crate::state::VisualState;

/// Cycles executed per second at each speed setting.
const SPEEDS: [u32; 7] = [1, 5, 25, 100, 500, 2000, 10_000];

/// A running visualizer.
pub struct App {
    mars: Mars,
    state: VisualState,
    speed: usize,
    paused: bool,
    outcome: Option<Outcome>,
}

impl App {
    /// Creates an application driving `mars`, starting paused.
    #[must_use]
    pub fn new(mars: Mars) -> Self {
        let state = VisualState::new(mars.core().size());
        Self { mars, state, speed: 3, paused: true, outcome: None }
    }

    /// Runs the event loop until the user quits.
    ///
    /// # Errors
    /// Returns any terminal I/O error. The terminal is always restored, even
    /// on error.
    pub fn run(&mut self) -> io::Result<()> {
        enable_raw_mode()?;
        io::stdout().execute(EnterAlternateScreen)?;
        let mut terminal = Terminal::new(CrosstermBackend::new(io::stdout()))?;
        let result = self.event_loop(&mut terminal);
        disable_raw_mode()?;
        io::stdout().execute(LeaveAlternateScreen)?;
        result
    }

    fn event_loop<B: ratatui::backend::Backend>(
        &mut self,
        terminal: &mut Terminal<B>,
    ) -> io::Result<()> {
        let frame_time = Duration::from_millis(33);
        loop {
            let started = Instant::now();
            terminal.draw(|frame| render(frame, &self.mars, &self.state))?;
            self.state.decay();

            if self.handle_input(frame_time.saturating_sub(started.elapsed()))? {
                return Ok(());
            }

            if !self.paused && self.outcome.is_none() {
                let budget = (SPEEDS[self.speed] / 30).max(1);
                for _ in 0..budget {
                    if let Some(outcome) = self.mars.outcome() {
                        self.outcome = Some(outcome);
                        self.paused = true;
                        break;
                    }
                    self.mars.step(&mut self.state);
                }
            }
        }
    }

    /// Handles pending input. Returns `true` when the user has asked to quit.
    fn handle_input(&mut self, timeout: Duration) -> io::Result<bool> {
        if !event::poll(timeout)? {
            return Ok(false);
        }
        let Event::Key(key) = event::read()? else {
            return Ok(false);
        };
        if key.kind != KeyEventKind::Press {
            return Ok(false);
        }
        match key.code {
            KeyCode::Char('q') | KeyCode::Esc => return Ok(true),
            KeyCode::Char(' ') => self.paused = !self.paused,
            KeyCode::Char('s') => {
                if self.mars.outcome().is_none() {
                    self.mars.step(&mut self.state);
                }
                self.paused = true;
            }
            KeyCode::Char('+') | KeyCode::Char('=') => {
                self.speed = (self.speed + 1).min(SPEEDS.len() - 1);
            }
            KeyCode::Char('-') => self.speed = self.speed.saturating_sub(1),
            _ => {}
        }
        Ok(false)
    }
}
```

This is the correctness oracle the whole classic dialect exists to be measured against. pMARS is not packaged for Homebrew, so it is built from source once into `tools/pmars/`, which is gitignored. Every differential test is gated on the binary existing, so a fresh clone still has a green test suite; CI runs the build script first.

The comparison is on **battle outcome and surviving process counts** over a matrix of warrior pairs, seeds, and core configurations. A cycle-by-cycle core diff is the stronger check, so it is also implemented, using pMARS's `-V` trace only where feasible; where it is not, the outcome comparison over many configurations is what catches divergence.

```rust
//! Differential testing against pMARS, the reference implementation.
//!
//! Any divergence in classic mode is a bug in CoreWarz. These tests are
//! skipped when the pMARS binary is absent; build it with
//! `tools/build-pmars.sh`.

use std::path::{Path, PathBuf};
use std::process::Command;

use corewarz_asm::assemble;
use corewarz_core::{Config, Mars, NullObserver, Outcome, Warrior, WarriorId};

fn repo_root() -> PathBuf {
    Path::new(env!("CARGO_MANIFEST_DIR")).join("../..").canonicalize().expect("repo root")
}

fn pmars_binary() -> Option<PathBuf> {
    let path = repo_root().join("tools/pmars/pmars");
    path.is_file().then_some(path)
}

fn corpus() -> Vec<PathBuf> {
    let dir = repo_root().join("tests/corpus");
    let mut files: Vec<PathBuf> = std::fs::read_dir(&dir)
        .expect("corpus directory exists")
        .filter_map(Result::ok)
        .map(|e| e.path())
        .filter(|p| p.extension().is_some_and(|e| e == "red"))
        .collect();
    files.sort();
    files
}

fn load(path: &Path, config: &Config) -> Warrior {
    let source = std::fs::read_to_string(path).expect("warrior file readable");
    let mut w = assemble(&source, config)
        .unwrap_or_else(|e| panic!("{} must assemble as classic Redcode: {e}", path.display()));
    w.name = path.file_stem().unwrap().to_string_lossy().into_owned();
    w
}

/// Runs pMARS on two warriors at fixed positions and returns, for each
/// warrior, whether it survived.
fn pmars_survivors(
    binary: &Path,
    config: &Config,
    a: &Path,
    b: &Path,
    positions: (u32, u32),
) -> Vec<bool> {
    let output = Command::new(binary)
        .args([
            "-r", "1",
            "-s", &config.core_size.to_string(),
            "-c", &config.max_cycles.to_string(),
            "-p", &config.max_processes.to_string(),
            "-l", &config.max_length.to_string(),
            "-d", &config.min_separation.to_string(),
            "-F", &positions.1.to_string(),
            "-b",
        ])
        .arg(a)
        .arg(b)
        .current_dir(repo_root())
        .output()
        .expect("pmars runs");
    assert!(output.status.success(), "pmars failed: {}", String::from_utf8_lossy(&output.stderr));

    // `-b` gives brief output: one "W L T" score line per warrior.
    let text = String::from_utf8_lossy(&output.stdout);
    let wins: Vec<u32> = text
        .lines()
        .filter_map(|line| line.split_whitespace().next())
        .filter_map(|token| token.parse::<u32>().ok())
        .collect();
    assert_eq!(wins.len(), 2, "expected two score lines, got: {text}");
    wins.iter().map(|w| *w > 0).collect()
}

fn corewarz_survivors(config: &Config, warriors: Vec<Warrior>, positions: &[u32]) -> Vec<bool> {
    let count = warriors.len();
    let mut mars = Mars::try_new(*config, warriors, positions).expect("warriors are admissible");
    let outcome = mars.run(&mut NullObserver);
    match outcome {
        Outcome::Win(WarriorId(id)) => (0..count).map(|i| i == id as usize).collect(),
        Outcome::Tie | Outcome::Draw => (0..count)
            .map(|i| mars.process_count(WarriorId(i as u8)) > 0)
            .collect(),
    }
}

#[test]
fn classic_battles_match_pmars() {
    let Some(binary) = pmars_binary() else {
        eprintln!("skipping: tools/pmars/pmars not built — run tools/build-pmars.sh");
        return;
    };

    let configs = [
        Config::default(),
        Config { core_size: 800, max_cycles: 8000, max_length: 20, min_separation: 20, ..Config::default() },
        Config { core_size: 55_440, max_cycles: 500_000, max_length: 200, min_separation: 200, ..Config::default() },
    ];

    let files = corpus();
    let mut compared = 0;
    for config in configs {
        for (i, a) in files.iter().enumerate() {
            for b in files.iter().skip(i + 1) {
                for offset in [100u32, 1234, config.core_size / 2, config.core_size - 150] {
                    if offset < config.min_separation
                        || config.core_size - offset < config.min_separation
                    {
                        continue;
                    }
                    let positions = [0, offset];
                    let ours = corewarz_survivors(
                        &config,
                        vec![load(a, &config), load(b, &config)],
                        &positions,
                    );
                    let theirs =
                        pmars_survivors(&binary, &config, a, b, (0, offset));
                    assert_eq!(
                        ours,
                        theirs,
                        "divergence: {} vs {} at offset {offset}, core {}",
                        a.display(),
                        b.display(),
                        config.core_size
                    );
                    compared += 1;
                }
            }
        }
    }
    assert!(compared > 0, "the matrix must actually run");
    eprintln!("compared {compared} battles against pMARS");
}

        assert!(

            "{} must be legal classic Redcode",

        );
    }
```

```rust
//! Invariants that must hold for every warrior, however nonsensical.

use corewarz_core::{
    AddrMode, Config, Dialect, Instruction, Mars, Modifier, NullObserver, Opcode, Warrior,
    WarriorId,
};
use proptest::prelude::*;

const ALL_OPCODES: [Opcode; 31] = [
    Opcode::Dat, Opcode::Mov, Opcode::Add, Opcode::Sub, Opcode::Mul, Opcode::Div, Opcode::Mod,
    Opcode::Jmp, Opcode::Jmz, Opcode::Jmn, Opcode::Djn, Opcode::Spl, Opcode::Seq, Opcode::Sne,
    Opcode::Slt, Opcode::Nop, Opcode::And, Opcode::Or, Opcode::Xor, Opcode::Shl, Opcode::Shr,
    Opcode::Not, Opcode::Tst, Opcode::Jez, Opcode::Jnz, Opcode::Jlz, Opcode::Jgz, Opcode::Call,
    Opcode::Ret, Opcode::Push, Opcode::Pop,
];

const ALL_MODIFIERS: [Modifier; 7] = [
    Modifier::A, Modifier::B, Modifier::AB, Modifier::BA, Modifier::F, Modifier::X, Modifier::I,
];

const ALL_MODES: [AddrMode; 8] = [
    AddrMode::Immediate, AddrMode::Direct, AddrMode::IndirectA, AddrMode::IndirectB,
    AddrMode::PredecA, AddrMode::PredecB, AddrMode::PostincA, AddrMode::PostincB,
];

const CORE_SIZE: u32 = 800;

fn any_instruction() -> impl Strategy<Value = Instruction> {
    (
        0..ALL_OPCODES.len(),
        0..ALL_MODIFIERS.len(),
        0..ALL_MODES.len(),
        0u32..CORE_SIZE,
        0..ALL_MODES.len(),
        0u32..CORE_SIZE,
    )
        .prop_map(|(op, md, am, a, bm, b)| Instruction {
            opcode: ALL_OPCODES[op],
            modifier: ALL_MODIFIERS[md],
            a_mode: ALL_MODES[am],
            a,
            b_mode: ALL_MODES[bm],
            b,
        })
}

fn any_warrior() -> impl Strategy<Value = Warrior> {
    proptest::collection::vec(any_instruction(), 1..20)
        .prop_map(|code| Warrior { name: "random".into(), code, start: 0 })
}

fn config() -> Config {
    Config {
        core_size: CORE_SIZE,
        max_cycles: 2000,
        max_processes: 64,
        max_length: 20,
        min_separation: 20,
        dialect: Dialect::Extended,
    }
}

proptest! {
    #![proptest_config(ProptestConfig::with_cases(400))]

    /// No sequence of instructions can drive a program counter, a process
    /// count, or a written address outside its legal range.
    #[test]
    fn invariants_hold_for_random_warriors(a in any_warrior(), b in any_warrior()) {
        let config = config();
        let mut mars = Mars::try_new(config, vec![a, b], &[0, 400])
            .expect("random warriors are admissible in extended mode");

        for _ in 0..config.max_cycles {
            if mars.outcome().is_some() {
                break;
            }
            mars.step(&mut NullObserver);

            for index in 0..2u8 {
                let id = WarriorId(index);
                prop_assert!(
                    mars.process_count(id) <= config.max_processes as usize,
                    "process count exceeded the limit"
                );
                if let Some(pc) = mars.process_pc(id) {
                    prop_assert!(pc < config.core_size, "program counter escaped the core");
                }
            }
        }
    }

    /// Every battle terminates. If this hangs, the run loop is wrong.
    #[test]
    fn every_battle_terminates(a in any_warrior(), b in any_warrior()) {
        let config = config();
        let mut mars = Mars::try_new(config, vec![a, b], &[0, 400]).unwrap();
        let _ = mars.run(&mut NullObserver);
        prop_assert!(mars.cycle() <= config.max_cycles);
    }

    /// Assembling a disassembly reproduces the instruction exactly, for any
    /// instruction the assembler would accept.
    #[test]
    fn disassembly_round_trips(instr in any_instruction()) {
        use corewarz_asm::{assemble, disassemble_instruction, legal_modifiers};

        let legal = legal_modifiers(instr.opcode);
        // Skip combinations the assembler legitimately rejects; Task 8 covers
        // the legal ones exhaustively, and this covers random field values.
        prop_assume!(legal.is_empty() || legal.contains(&instr.modifier));

        let text = disassemble_instruction(instr);
        let config = Config { dialect: Dialect::Extended, core_size: CORE_SIZE, ..Config::default() };
        let back = assemble(&text, &config).expect("canonical text must reassemble");
        let mut expected = instr;
        if legal.is_empty() {
            // Modifier-less opcodes disassemble without a modifier, so the
            // assembler supplies the default.
            expected.modifier = back.code[0].modifier;
        }
        prop_assert_eq!(back.code[0], expected);
    }
}

#[test]
fn a_warrior_of_every_single_opcode_runs_without_panicking() {
    // The narrowest possible smoke test for dispatch coverage: each opcode,
    // alone, executed once.
    for opcode in ALL_OPCODES {
        for modifier in ALL_MODIFIERS {
            let instr = Instruction {
                opcode,
                modifier,
                a_mode: AddrMode::Direct,
                a: 1,
                b_mode: AddrMode::Direct,
                b: 2,
            };
            let w = Warrior { name: "single".into(), code: vec![instr], start: 0 };
            let mut mars = Mars::try_new(config(), vec![w], &[0]).unwrap();
            mars.step(&mut NullObserver);
        }
    }
}
```
